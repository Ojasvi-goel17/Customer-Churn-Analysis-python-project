# Telco Customer Churn Analysis Using Python

## Project Overview
This project analyzes the Telco Customer Churn dataset using Python to identify the major factors influencing customer attrition. The analysis focuses on customer demographics, contract types, services used, and payment methods to uncover patterns related to churn.

---

## Objective
The main objective of this project is to:
- Analyze customer churn behavior
- Identify high-risk customer segments
- Generate business insights for customer retention

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code

---

## Data Cleaning & Preprocessing
The following preprocessing steps were performed:
- Converted `TotalCharges` data type from object to float
- Handled missing and empty values
- Checked for duplicate records
- Performed feature engineering on the `SeniorCitizen` column

---

## Exploratory Data Analysis (EDA)
The project includes:
- Overall churn analysis
- Demographic analysis
- Contract type analysis
- Tenure analysis
- Internet service analysis
- Payment method analysis
- Service usage analysis

Visualizations were created using Matplotlib and Seaborn to identify churn trends and customer behavior patterns.

---

## Key Insights
- Customers with Month-to-Month contracts have the highest churn rate
- New customers are more likely to churn
- Customers without Online Security and Tech Support churn more frequently
- Fiber Optic users showed higher churn compared to DSL users
- Electronic Check users had the highest churn among payment methods

---

## Business Recommendations
- Improve retention strategies for new customers
- Encourage long-term contracts through offers and discounts
- Promote bundled security and support services
- Investigate customer dissatisfaction among Fiber Optic users

---

## Outcome
This project helped in understanding customer churn patterns and applying data analysis techniques using Python for business problem solving.
